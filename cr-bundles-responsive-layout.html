Responsive layout guidelines

UI notes

Left column

  • Title and subtitle never truncate. No ellipsis — the text always wraps onto more lines.
  • Words break only as a last resort — only when a single word does not fit even a full line.

Right column

  • Price and price suffix always stay together on one line (“$7.49 / ea” never splits).
  • Price prefix may wrap onto its own line.
  • Price is always vertically centered in the card.

Column relationship

  • The gap between the left and right column is 20px.
  • When the title or subtitle no longer fits in two lines, the price splits onto two lines — price prefix on the first, price and price suffix on the second — freeing width for the text.
  • The left column gets all the space the right column does not need — when the price splits, the freed width goes to the text.

Title badge

  • The badge sits beside the title as long as both fit on one line.
  • Once the title and badge no longer fit on one line, the badge moves below the title.

Consistency across cards

  • What happens in one card happens in all of them. When the badge moves below the title, or the price splits onto two lines, it applies to every tier at once.
Claude’s dev notes

Why CSS alone is not enough

  • “The title wrapped” is not a CSS condition. There is no selector for “this text wrapped onto two lines”.
  • CSS cannot pass state between cards. There is no way to say “if it happened in one card, apply it to its siblings”.
  • JS therefore only measures how many lines the text actually occupies and toggles two CSS rules accordingly. All rendering is still done by CSS.

Implementation notes

  • Assume nothing about typography. In the merchant’s theme the title can have any font size and line height — the line count has to be measured, not derived from a constant.
  • Always measure in the same baseline state, with both rules switched off. Otherwise the layout flickers between two states as the width changes.
  • Re-measure once the theme’s fonts have loaded. Before that the text widths differ and the decision is made on the wrong numbers.
  • The order of the decisions is not arbitrary. Badge placement is derived from the title; splitting the price is a choice. First try the price on one line, derive the badge from the result and check the limits; only if that fails does the price give way. With a fixed order for both rules the layout over-corrects — it makes both concessions where one was enough.
